# 👁️ Python OpenCV Face Detection

A lightweight and efficient face detection project built using Python and OpenCV to detect and locate human faces in images and real-time video streams.

---

## 🚀 Features
* **Real-Time Detection:** Works with webcam feeds or pre-recorded video files.
* **OpenCV Powered:** Utilizes OpenCV's robust computer vision tools and pre-trained classifiers (like Haar Cascades).
* **Lightweight:** Minimal dependencies and fast execution.
* **Easy to Setup:** Simple script structure that's easy to run and modify.

---

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Core Library:** OpenCV (`cv2`)
